# 占位素材

把宠物立绘存成 **`pata.png`**（或 `.webp` / `.jpg`）放在这个目录，游戏启动时会自动用它替换程序化绘制的矢量兔子。
目录为空时自动回退到矢量版，构建不受影响。

建议：正方形、透明背景、宠物占画面 85% 左右，短边 ≥ 512px。

## 地板 / 墙纸贴图

文件名按 **`surface-<tex>.png`** 命名，`<tex>` 对应 `src/data/furniture.ts` 里 `FLOORS` / `WALLS`
某一项的 `tex` 字段。贴图缺失时自动回退到该项的 `main`/`accent` 纯色，不用改代码。

现有三张：`surface-star-stripe.png` ↔ 墙纸「星星彩条」，
`surface-pink-panel.png` ↔ 地板「粉调拼花」，`surface-white-grid.png` ↔ 地板「雪白细格」。

两种面的铺法不一样，做图前先看清楚：

- **墙**：不做等距斜切，按屏幕正方向铺，竖条纹才不会歪、图案才不会倒。
  适合**竖条纹 / 满铺小图案**，横向缩放到刚好盖住两面墙，按宽:高 ≈ 2.6:1 准备。
- **地板**：跟着等距透视斜切，方格会变成菱形贴在地上。
  只取**左上角的正方形区域**（边长 = 短边），正好铺满 8×8 的地格，所以图案要能在正方形内自洽，
  右边超出正方形的部分不会被用到。
